# Customer Anomaly Detection using DBSCAN

## Overview

This project uses the DBSCAN clustering algorithm to identify anomalous customers based on their purchasing behavior.

## Dataset

Wholesale Customers Dataset

Features:

* Fresh
* Milk
* Grocery
* Frozen
* Detergents_Paper
* Delicassen

## Algorithm

* DBSCAN
* StandardScaler

## Features

* Customer anomaly detection
* Interactive Streamlit interface
* Real-time predictions
* Simple visualizations

## Run Project

Install dependencies:

pip install -r requirements.txt

Train model:

python src/train.py

Run app:

streamlit run app.py

## Technologies

* Python
* Scikit-Learn
* Pandas
* Streamlit
* Joblib
