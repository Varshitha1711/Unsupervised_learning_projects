# Hierarchical Clustering Customer Segmentation

## Objective

Group customers based on:

- Age
- Annual Income
- Spending Score

using Hierarchical Clustering.

---

## Algorithm

Agglomerative Clustering

Linkage Method:
- Ward

---

## Evaluation

Silhouette Score

---

## Deployment

Streamlit Dashboard

---

## Run Training

```bash
python src/train.py
```

## Evaluate

```bash
python src/evaluate.py
```
